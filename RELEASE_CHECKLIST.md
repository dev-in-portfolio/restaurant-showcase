# Showcase Release Checklist

This checklist must be fully verified and approved before a website can be merged into the `main` branch of the Showcase repository.

## 1. Information Completeness
- [ ] Legal name is spelled correctly.
- [ ] Complete address, phone number, and hours are present and verified.
- [ ] Online presence comparison link is accurate and configured.

## 2. Review and Sign-offs
- [ ] Desktop viewport rendering is checked and approved.
- [ ] Mobile viewport rendering is checked and approved.
- [ ] Screen layout flow is accessible and logical.
- [ ] Keyboard focus states are styled and active.

## 3. Production Quality
- [ ] No dummy text or placeholder files.
- [ ] Images optimized for fast loading.
- [ ] Floating comparison button present on all pages.
- [ ] Staging-to-Showcase promotion script runs with zero errors.
- [ ] Final visual signature sign-off.
